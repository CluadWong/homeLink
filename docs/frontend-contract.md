# 前端契约（Vue 重建）

## 1. 硬约束

- 前端独立应用，**只走 HTTP**：不读数据库、不 import 后端模块、不共享文件。
- token 优先**部署期注入**（`VITE_API_TOKEN`）；未注入时允许在「设置」里填写一次，仅存 **sessionStorage**（不可用时仅存当前页面内存），关闭标签页即失效。禁止写入 `localStorage` 或任何持久化存储；刷新后优先从注入配置重建。详见 §8。
- **不做乐观 UI**：点击后等服务端返回再改界面。
- 无 WebSocket，一律轮询，且只轮询只读接口。
- 时间参数一律 ISO UTC，展示时转本地时区。
- 错误必须转成人话，界面不出现裸错误码；`trace_id` 默认折叠。
- 本期设备**不可启停**，界面不提供启停开关。

## 2. 六页地图与接口

| 页 | 主要接口 | 刷新节奏 |
| --- | --- | --- |
| 调用（默认） | `GET /api/devices`（取功能列表）、`POST /api/control` | 进入拉一次；执行成功后重拉 `GET /api/state` |
| 设备 | `GET /api/rooms`、`GET /api/devices`、设备/房间 CRUD | 进入拉一次；写后重拉 |
| 学码 | `POST /api/devices`（`learn_draft`）、`POST /api/learn/start`、`GET /api/learn/capture`、`POST /api/learn/save`、`POST /api/learn/cancel` | `capture` 每 1 秒 |
| 状态 | `GET /api/state`、`GET /api/gateway` | 每 5 秒一次 |
| 校正 | `GET /api/state`、`POST /api/correct` | 进入拉一次 |
| 审计 | `GET /api/audit` | 进入 / 改筛选时拉一次 |

- **调用页没有参数表单**：只列设备下的功能（`id,name`），每个功能一个「执行」按钮，点击即 `POST /api/control {function_id}`。
- 状态页 5 秒轮询通常命中后端 **15 秒探测缓存**；只有用户点「重新检测」时才带 `refresh=true`。
- 学码页必须**先建设备再开会话**：`learn_draft=true` 创建成功后调 `start`；任一步失败都要调 `cancel` 撤壳。
- 设备页房间管理：界面只收显示名（`display_name`）；内部 `name` 由前端派生，限定 `[a-z0-9_]`、长度 1–24，并保证在当前房间集合内唯一。重名（含并发写入返回 409 `CONFLICT`）时提示「状态冲突：房间 xxx 已存在」，引导刷新后重试；界面不要求用户填写英文标识。

导航规则：

- 导航放主区顶部横向，不放侧边栏；调用页排第一；设置（服务地址、token 状态）折叠，正常路径不展示 token。
- 状态摘要条常驻，任何页都能看到设备概况与网关状态；状态页可一键跳「校正」。
- 离开学码页调一次 `cancel`：SPA 路由跳转由 `onBeforeRouteLeave` / `onBeforeUnmount` 触发；整页刷新或关闭标签页不属于路由离开，额外监听 `pagehide` 并用 `fetch(..., {keepalive:true})` 发送同一取消请求。两条路径只取消一次；已 `save` 成功则不再取消。

### 学码轮询与异常

- `capture` 每 **1 秒**一次；`captured=true` 立即停止轮询，进入命名保存。
- `no_signal`：继续轮询，提示「还没收到，请再按一次」。
- `malformed`：继续轮询，提示「收到的波形无法解析，请重新按一次」。
- `gateway_unreachable`：继续轮询，提示「网关连接不上，去状态页确认后重试」。
- 401 `DEVICE_UNAUTHORIZED`：停止轮询并 `cancel` 撤壳，按「板子拒绝访问」展示，核对网关用户名密码与板子配置。
- 404 `NOT_FOUND`：会话不存在或已被 TTL 回收，停止轮询，提示「本次学码已结束，请重新开始」。
- 其它异常（网络中断、超时、5xx `INTERNAL_ERROR` 等非 401）：**立即停止轮询 → 尽力 `cancel` 撤壳 → 展示该错误码的人话与下一步**（网络中断显示「管家服务连不上」；5xx 显示「管家内部出错」），不保留半开会话，不出现裸错误码与堆栈。
- 客户端 10 分钟（600 秒）兜底超时与服务端 TTL 对齐：超时即停止轮询并 `cancel`，提示「本次学码已结束，请重试」。

## 3. 状态与传感器

| `state_source` | 展示 | 规则 |
| --- | --- | --- |
| `unknown` | 「未知」灰色 | **绝不渲染成「关」**，开关控件不得默认 off |
| `confirmed` | 「已确认」 | 仅用户校正后出现 |

- 回放后一律 `unknown`：红外单向无回执，界面不得暗示「已经开/关」。
- 传感器 `available=false` 时三项显示「未接入」，**不得显示 0**。
- 校正可选值 `on` / `off` / `unknown`（后端接受非空自由字符串，界面只给这三项）。
- 状态页对非标准 `state` **原样显示**，不做中英文映射；超过 **12 字符**截断并加省略号（hover/title 显示全文）。

## 4. 错误码 → 人话 + 下一步

| 码 | 人话 | 下一步 | 折叠 trace |
| --- | --- | --- | --- |
| `UNAUTHORIZED` | 鉴权失败 | 检查部署注入的 token | 否 |
| `INVALID_REQUEST` | 请求字段有问题 | 检查是否缺字段或带了不认识的字段 | 否 |
| `NOT_FOUND` | 找不到设备或功能 | 刷新设备列表，确认是否已被删 | 否 |
| `CONFLICT` | 状态冲突 | 刷新后重试 | 否 |
| `DEVICE_OFFLINE` | 设备没有响应 | 查状态页网关、板子电源 / Wi-Fi / 地址 | 是 |
| `DEVICE_UNAUTHORIZED` | 板子拒绝访问 | 核对网关用户名密码与板子配置 | 是 |
| `INTERNAL_ERROR` | 管家内部出错 | 报告给我们 | 是 |
| `AGENT_UNREACHABLE`（客户端展示码） | 管家服务连不上 | 确认后端已启动、地址正确 | 是 |

**两类「连不上」必须分开**：服务连不上 = 请求没到达后端；网关离线 = 后端正常、板子不通。文案、颜色、下一步都不同，禁止合并成「网络错误」。

**`AGENT_UNREACHABLE` 是客户端展示码，不在服务端 7 个错误码之内**：只在请求未到达后端（网络不可达、超时）时由前端生成；后端既不返回该值，也不接受请求携带它，请求体与响应中永远不出现该值。

## 5. 措辞规则

- 控制成功只能说「**已发送**」，不得说「已开启」「已调到 26 度」。
- 功能列表只展示用户起的名字；界面不展示、也不猜测功能对应的具体动作。
- 学码文案：开始「请对准接收头按下遥控器」；未捕获「还没收到，请再按一次」；成功「已捕获 N 段波形，请命名保存」；超时「本次学码已结束，请重试」。
- 删除设备/学码功能必须二次确认，并说明「会同时删除其红外码」；失败一律给出「发生了什么 + 下一步做什么」，不出现裸码与堆栈。

## 6. Vue 实现约束

- 统一 HTTP 客户端：注入 base URL 与 token，集中处理 401、超时、错误形状。
- 路由刷新后必须能从 URL 与服务端重建页面，不依赖内存中的上一步状态。
- 不缓存业务数据到本地存储；离线只显示「服务连不上」，不展示陈旧状态。
- 组件不得自行拼装请求字段；字段名以 `api-contract.md` 为准；响应里没有参数规格、没有能力字段，不得凭空渲染参数控件。

## 7. 加载、空态与断线

- **加载中**：显示骨架或「正在读取」，不得先渲染成「关」再纠正。
- **空数据**：无设备给「去添加设备」入口；设备下无功能给「去学码」入口；空房间「暂无设备」；审计无记录「暂无记录」。
- **服务连不上**：整页降级为离线提示 + 重试，保留导航但不展示陈旧状态；任何 401 统一引导到「检查部署注入的 token」，不在页面自动弹出输入框。
- **token 缺失**：401 后在「设置」折叠区手动填写一次即可继续，不打断当前页面的其余操作。

## 8. 部署变量与 token

部署期变量（Vite，构建时注入）：

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `VITE_API_TOKEN` | 否 | 后端 `api.token`；为空表示后端不校验，前端也不带 `Authorization` |
| `VITE_API_BASE_URL` | 否 | 默认空串 = 同源 `/api`；开发期由 Vite proxy 转发到 `127.0.0.1:8000` |

token 三档优先级：

1. **部署注入** `VITE_API_TOKEN`：构建产物自带，刷新后从构建配置重建；存在时忽略运行时输入。
2. **当次输入**：未注入时，允许在「设置」里填写一次，只写 **sessionStorage**（键 `jj_butler_api_token`）；storage 不可用时仅存当前页面内存。
3. **未授权**：两者都没有时，请求不带 `Authorization`，后端返回 401 `UNAUTHORIZED`，界面显示「鉴权失败」并引导检查注入或到「设置」填写。

sessionStorage 生命周期：同一标签页内刷新、前进/后退仍有效；**关闭标签页或浏览器即清空**；新标签页不共享；不写入 `localStorage`、IndexedDB、Cookie 等任何持久化存储。401 后可随时在「设置」重新填写或清空。
